# Documentation — Transform2D.cpp Implementation

## Overview
The `Transform2D` class implements a 3x3 affine transformation matrix for 2D points and directions following DirectX-style conventions:
- Row-major storage: `m[row][col]`;
- Row vectors: points are represented as [x, y, 1] and directions as [x, y, 0];
- Translation is stored in the third row: `m[2][0] = tx`, `m[2][1] = ty`;
- The third column is [0, 0, 1]^T for 2D affine transforms;
- Transform composition order reads left to right: v * (A * B) == (v * A) * B, applying transform A first, then B.

## Factories Implementation
- `translation(float tx, float ty)`: returns an identity matrix with translation offsets assigned to `m[2][0]` and `m[2][1]`;
- `rotation(float angle_rad)`: returns a matrix configured with counter-clockwise rotation (m[0][0] = cos(a), m[0][1] = sin(a), m[1][0] = -sin(a), m[1][1] = cos(a));
- `scale(float sx, float sy)`: returns a diagonal scaling matrix with m[0][0] = sx and m[1][1] = sy.

## Matrix Multiplication and Composition
- `operator*(const Transform2D& rhs)`: calculates the matrix product `*this * rhs`, maintaining row-major transformation concatenation;
- `operator*=(const Transform2D& rhs)`: assigns the resulting matrix multiplication product in place.

## Coordinate Transformations
- `transform_point(const Vector2D& point)`: computes [p.x, p.y, 1] * M, applying both linear transformation and spatial translation;
- `transform_vector(const Vector2D& direction)`: computes [d.x, d.y, 0] * M, ignoring translation (third row) to transform direction only.
